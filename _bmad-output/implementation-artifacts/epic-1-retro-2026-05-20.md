## 4. Challenges & Technical Friction

Despite an overall clean execution, several systemic challenges were encountered and successfully resolved:

- **Docker Bind Mount Scope (Story 1.1):** Broad backend compose mounts hid the local Python virtual environment. This was resolved by narrowing the mount path strictly to `./backend/app:/app/app`.
- **Database Lifespan Health Check Hangs (Story 1.3):** Early database and Redis health check implementations lacked async timeouts, creating a risk of infinite startup hangs during connectivity issues. Resolved by introducing explicit async timeouts.
- **Test Environment Mock Leakage (Story 1.3):** Unit testing of persistent lifespans risked spilling test mocks into the production lifespan. Standardized isolation was implemented.
- **Dio Error swallowing (Story 1.5):** An early Dio interceptor swallowed 4xx error codes, manifesting as silent layout failures instead of structured error states. Resolved by correcting the envelope parser.
- **Widget Overflows & Animation Resets (Story 1.6):** Custom widgets encountered horizontal layout overflows in compact views (`_FullVariant` structures) and pulsing dot animation controller reset issues. Patched with flexible layout constraints and strict lifecycle animation disposals.

---

## 5. Key Insights & Systemic Learnings

- **Systemic Isolation over Quick Fixes:** Taking the time to narrow bind mounts and isolate testing lifespans prevented a massive category of future environmental issues.
- **Proactive Resiliency as a Standard:** Building failovers, backoffs, and health check timeouts in the skeleton phase prevents downstream cascades as we build out heavy multi-agent workloads.
- **Strict UI Contract Alignment:** Establishing screen-tier-adaptive responsive configs and golden widget tests early guarantees that future layouts will scale without design regressions.
